Backend Engineer

A real-time operations dashboard for a logistics SaaS — built from scratch with Node, Postgres and a custom WebSocket layer that pushes shipment events to thousands of dispatcher clients with sub-200ms latency.

I owned the full backend rewrite: domain modelling, event sourcing for the audit trail, and a typed RPC layer between services. On the frontend I rebuilt the dispatch table around virtualised rows so the UI stays smooth even with 50k live shipments on screen.

The result: a 4× drop in incident-resolution time for the ops team and a clean foundation the rest of the platform now extends.
